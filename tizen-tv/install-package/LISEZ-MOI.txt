── CONTENU DU PACKAGE ──────────────────────────────────────────

── PRÉREQUIS ───────────────────────────────────────────────────

  ✓ TV Samsung Smart TV (2016 ou plus récente, Tizen 3.0+)
  ✓ TV et PC sur le même réseau Wi-Fi
  ✓ Windows 10 ou 11
  ✓ Un PIPSILY-TV-signed.wgt signé POUR CETTE TV  ← voir ci-dessous

── IMPORTANT : LE PACKAGE DOIT ÊTRE SIGNÉ POUR TA TV ───────────

  Une TV Samsung n'accepte que les applications dont le certificat
  a été émis par Samsung, et ce certificat est lié au numéro
  d'identification unique (DUID) de TA TV.

  Autrement dit :
    - il n'existe pas de .wgt qui s'installe sur n'importe quelle TV
    - un certificat fabriqué localement est toujours refusé
      (erreur "install failed[118019]")

  Pour obtenir un package valide, il faut, une seule fois :

    1. Installer Tizen Studio + l'extension Samsung TV
       https://developer.samsung.com/smarttv
    2. Tools → Certificate Manager → « + » → Samsung
    3. Se connecter avec un compte Samsung Developer (gratuit)
    4. Renseigner le DUID de la TV
       (l'installateur te l'affiche à l'étape 2)
    5. Signer le package avec ce profil

  Procédure détaillée : tizen-tv/TIZEN-README.md dans le dépôt.

  L'installateur vérifie le package AVANT de tenter l'installation
  et te dit précisément ce qui manque.

── INSTALLATION EN 3 ÉTAPES ────────────────────────────────────

  ÉTAPE 1 — Activer le mode développeur sur la TV
  ─────────────────────────────────────────────────
  1. Sur ta télécommande Samsung : touche Accueil
  2. Paramètres (⚙) → Support → À propos de ce TV
  3. Clique 5 fois sur le NUMÉRO DE MODÈLE affiché à l'écran
  4. Un dialogue "Mode développeur" apparaît → Sélectionner ON
  5. Entrer l'adresse IP de ton PC Windows
     (Paramètres Windows → Wi-Fi → Propriétés → Adresse IPv4)
  6. Confirmer → la TV redémarre

  ÉTAPE 2 — Trouver l'IP de ta TV
  ─────────────────────────────────
  Sur la TV : Paramètres → Général → Réseau → État du réseau
              → Informations IP
  Note l'adresse (exemple : 192.168.1.50)

  ÉTAPE 3 — Lancer l'installateur
  ─────────────────────────────────
  1. Double-cliquer sur INSTALLER.bat
  2. Suivre les instructions à l'écran
  3. Entrer l'adresse IP de la TV quand demandé
  4. L'application s'installe et se lance automatiquement !

── MISES À JOUR AUTOMATIQUES ───────────────────────────────────

  Une fois installée, PIPSILY TV se met à jour automatiquement
  à chaque lancement — aucune action requise.

  Réserve : la mise à jour télécharge le .wgt publié en release,
  qui est signé pour une TV donnée. Sur une autre TV, elle sera
  refusée et l'app proposera le lien de téléchargement à la place.

── DÉSINSTALLATION ─────────────────────────────────────────────

  TV : Applications → ⚙ (paramètres) → PIPSILY → Supprimer

── PROBLÈMES FRÉQUENTS ─────────────────────────────────────────

  "Connexion refusée"
  → Mode développeur non activé ou TV non redémarrée
  → Vérifier que TV et PC sont sur le même Wi-Fi

  "install failed[118019]" / "Certificat invalide"
  → Le package n'est pas signé avec un certificat Samsung émis
    pour le DUID de CETTE TV. Redémarrer la TV n'y changera rien :
    voir la section "LE PACKAGE DOIT ÊTRE SIGNÉ POUR TA TV".

  L'app ne se trouve pas dans le menu
  → Chercher dans Applications → Mes applications
